# FF1 Pixel Remaster — Cheat Engine 修改表

適用於本機 Steam build **20249397**，Windows 64-bit 遊戲；已在 CrossOver 的 Cheat Engine 中實測。

## 檔案

- `FF1_PR_20249397.CT`：整合以下四個獨立選項。
- `FF1_PR_Level99_20249397.CT`：目前四名隊員 Lv99，透過遊戲原本的升級流程同步經驗值和能力，保留職業。
- `FF1_PR_TopEquipment_20249397.CT`：29 種終盤武器、防具，各補足總持有數 4 件。包括正宗、石中劍、佐助之刀、龍甲、鑽石手鐲、聖盾、緞帶、守護戒指與實用法杖。完整清單見 `equipment.csv`。
- `FF1_PR_Elixir99_20249397.CT`：萬靈藥補至 99 個。
- `FF1_PR_Gil1000000_20249397.CT`：金錢設為 1,000,000 Gil；低於目標補足，高於目標調降，已等於目標則不變。

裝備加入背包後自行穿戴。部分裝備限進階職業；此表保留現有職業。正宗可供所有職業使用。裝備選擇涉及攻擊、防禦、抗性與道具施法，因此提供終盤裝備包供搭配。

## 使用

1. 先備份存檔，開啟遊戲、讀取存檔，停在城鎮或世界地圖。
2. Cheat Engine 選取 `FINAL FANTASY.exe`，開啟整合 CT 或所需的獨立 CT。
3. 勾選所需選項一次，等待完成訊息。重新開啟遊戲選單查看結果。
4. 確認後另存新欄位。取消勾選只關閉選項，不會還原修改。

每個選項只執行一次，不持續鎖定數值。道具重複執行只補足目標總數；已達目標時不再增加。金錢選項則固定設為 1,000,000。道具總持有數包含已裝備數量。

遊戲更新後若出現版本不符，需重新核對，不要直接移除版本檢查。PE timestamp 為 `1738582778`，SizeOfImage 為 `38342656`；這是相容性檢查，並非完整檔案雜湊。
